Gamography (SwiftUI)

01 / Ringkasan

Katalog gim untuk iOS dengan antarmuka SwiftUI yang bersih. Pencarian dan favorit tetap bekerja saat offline, gambar dimuat dengan pipeline asinkron, dan lapisan jaringan tetap tipis sehingga mengganti API tidak menimbulkan stres. Saya menyetel performa daftar untuk ponsel lama dan menambahkan beberapa perbaikan aksesibilitas untuk teks besar. Hasilnya terasa cepat namun tetap mudah dibaca.
