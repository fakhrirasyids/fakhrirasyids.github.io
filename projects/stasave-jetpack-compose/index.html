Stasave (Jetpack Compose)

01 / Overview

Status saver with a clean Compose surface and very few steps. It scans media folders, builds a fast thumbnail grid, and writes files with WorkManager so downloads keep going even if the app is backgrounded. The permission flow is short and direct, and a storage cleaner removes temporary bits after a successful save. I added a share action and a small snackbar system so users get immediate feedback. The codebase follows a simple MVVM pattern and each screen has a preview for quick UI review.
