Digihealth Kiosk ATM

01 / Overview

The Health Kiosk is a Kotlin Multiplatform application built with Jetpack Compose, running natively on Android, iOS, and Desktop from a single shared codebase. Deployed inside Digihealth ATM units in clinics and hospitals, it provides a self-service healthcare experience where patients can log in, join queues, schedule appointments, and review medical records. The kiosk connects to 10+ medical devices over BLE and USB, including weight scales, height sensors, oximeters, blood pressure monitors, and thermometers, collecting real-time vitals in a single session. AI modules handle health risk prediction, symptom triage, and intelligent recommendations based on the collected data. Shared domain logic covers device protocols, data synchronization, and offline queuing, while Compose Multiplatform renders a consistent, clinic-ready UI across all platforms.
