Sakuku (Kotlin)

01 / Overview

Personal finance app that tries to stay calm. Balances and goals are on one screen and you can drill down without losing context. I wrote small custom views for charts to avoid heavy dependencies and tuned them for low memory devices. Data syncs through Firebase which keeps setup light for a single user. The code is clean enough that a new contributor can add a screen in a day.
