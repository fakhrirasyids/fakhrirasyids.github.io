Hangman (Java)

01 / Overview

Small hangman game for Android built for quick play. It runs fully offline and never nags. Word packs live in the app, progress is saved locally, and the UI is large and readable. The code shows a clean separation between the game loop and the view which makes it a nice teaching sample.
