BeritaIn (SwiftUI)

01 / Overview

SwiftUI news reader that stays responsive on a slow connection. Articles are cached in Core Data and images are loaded with an async pipeline so scrolling stays smooth. I used Swinject for dependency injection to keep view code light. The layout supports multiple languages and I validated a few tricky truncation cases. CI runs SwiftLint and unit tests on each push, and a background refresh updates headlines while the app is idle.
