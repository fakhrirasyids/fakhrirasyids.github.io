8xray App

01 / 项目概述

8xray 是基于 Kotlin Multiplatform 与 Jetpack Compose 构建的应用，从单一共享代码库同时在 Android、iOS 和 Desktop 上原生运行。应用通过原生 DLL 和 SO 库与 X 光硬件通信，直接访问设备控制、实时图像采集和硬件层面的校准程序。应用拉取 DICOM 检查，支持医生标注发现、勾画感兴趣区域、测量角度与距离，并通过基于 OpenCV 的工具包微调对比度与窗宽窗位。全程采用离线优先策略：检查、编辑与备注本地保存，待网络恢复后同步至后端，确保查房与会诊不受网络状况影响。
