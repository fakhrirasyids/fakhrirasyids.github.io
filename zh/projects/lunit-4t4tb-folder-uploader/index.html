Lunit 4T4TB Folder Uploader

01 / 项目概述

使用 Python 与 PySide6 构建的桌面 GUI 工具，用于将医学影像文件夹批量上传至 Lunit 4T4TB 平台。界面支持选择根目录、预览目录树、配置上传设置，并实时监控每个文件的上传进度。后台 Worker 处理上传队列，保证大批量传输时 UI 依然流畅响应，内置日志面板记录错误及上下文信息，方便在不重启整批任务的情况下重试失败项。

02 / 技术栈

  • PySide6
  • Desktop GUI
